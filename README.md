# Signal Splitter Hub (91)

Build the frontend shell for a web application called "Signal Splitter".

Tagline:

"One Source. Every Platform. Zero Factual Drift."

This is a hackathon MVP for repurposing long-form content into platform-specific social media content while preserving factual accuracy.

Create a clean, modern SaaS dashboard.

MAIN FEATURES:

1. Header

- Signal Splitter logo

- Navigation:

  Dashboard

  Source Analysis

  Content Studio

  Fact Lock

  Quality Check

2. Dashboard

- Welcome section

- "Create New Content" button

- Recent projects section

- Four feature cards:

  Source Analysis

  Content Generation

  Fact Lock

  Quality Check

3. Source Analysis page

- Large textarea for pasting a source

- "Analyze Source" button

- Source summary area

- Key ideas

- Claims

- Statistics

- Entities

- Important quotes

- Intended audience

- Tone

- Purpose

4. Content Studio page

Create four output tabs:

- LinkedIn

- X Thread

- Instagram Carousel

- Short Video / Reel

Each output should have:

- Generated content area

- Copy button

- Edit button

- Regenerate button

5. Fact Lock page

Display claims in cards with:

- Claim

- Status

- Supporting source passage

- Explanation

Statuses:

Supported

Altered

Unsupported

Context Warning

6. Quality Check page

Show:

- Factual Consistency

- Source Coverage

- Brand Alignment

- Platform Suitability

Use progress indicators.

IMPORTANT:

Build the frontend structure and navigation first.

Use realistic mock data.

Do NOT implement authentication, payment, subscriptions, or unnecessary features.

Keep the code modular and component-based so other developers can integrate Source Analyzer, Fact Lock, and Quality Checker modules later.
